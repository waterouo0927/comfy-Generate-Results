# 心得
這次comfy的體驗是我很少接觸的AI生圖，有種科技真的在逐漸進步的感覺。<br>先說我的看法，我自己做遊戲的時候如果要在真人美術跟AI美術兩者做選擇的話，我會偏好於真人美術。<br>AI所產生，所畫出的感覺在現代的科技來看，仍是無法產生人類的溫度，讓作品會成為量產的產品一般。我認為這是現在AI生圖仍有的問題。<br>
目前我的想法是覺得AI生圖可以用在:
- 靈感思考(把自身想法生成出來先有一個架構)
- 細節增加(自身作品可以用AI去進行細節修改)
這樣在不失去設計師自身的風格與想法，將AI設定成輔助工具，而非主要創作工具，我認為這才是最好的使用方法。
## 針對comfy的想法。<br>
comfy目前用起來很新穎，功能非常多，讓很少完這方面工具的我玩得很快樂。<br>
遇到的最大問題也就是
- 顯卡要求:這應該是很多AI工具的問題，加上現在顯示卡價又居高不下。
- 模型大小:模型有點大，但也可能是我用不夠多生成式工具，但comfy真的有一點大｡ﾟヽ(ﾟ´Д`)ﾉﾟ｡
- 生成問題:這應該也是很多生成式工具的問題，要真的反覆很多次才能看到想要的成果，這次在做完後，我又反覆生了20多次，更改他的提示詞，才有我要的成果<br>
### 總而言之
撇開以上問題不談的話，comfy還是不錯，很適合第一次接觸這方面的人做使用
